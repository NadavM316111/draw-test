# draw-test

A React Drawing App with localStorage persistence, undo/redo, color picker, brush controls, eraser, and PNG export.

## Features
- 🎨 10 preset colors + custom color picker
- 📏 Adjustable brush size (1–40px)
- ⬜ Eraser tool
- ↩ Undo / ↪ Redo (20-state history)
- 🗑 Clear canvas
- ⬇ Download as PNG
- 📱 Touch support
- 💾 Auto-saves to localStorage

## Usage
```jsx
import DrawingApp from './DrawingApp';
export default function App() { return <DrawingApp />; }
```
